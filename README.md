# المرصد — NewsStand

صحيفة عربية مبنية على Next.js وReact وSupabase. الاسم الحالي مؤقت. الأقسام بالترتيب: المحلية، السياسة، الاقتصاد، الرياضة، الثقافة، الترفيه، منوعات، سياحة وسفر.

## التشغيل

استخدم Node.js 22 ثم `npm ci`. انسخ `.env.example` إلى `.env.local` واضبط رابط Supabase ومفتاح القراءة العام. شغّل `npm run dev` للتطوير أو `npm run build` ثم `npm start` للإنتاج.

## قاعدة البيانات

لتهيئة مشروع جديد، طبّق `supabase/setup.sql` فقط. ملفات SQL المرقمة القديمة توثق تطور النسخة الأولية؛ لا تُطبّقها بعد ملف التهيئة الموحد.

جدول `articles` محمي بسياسات RLS. الزائر يستطيع قراءة الأخبار التي حلّ موعد نشرها فقط، ولا يستطيع الإضافة أو التعديل. يبقى الخبر مسودة عندما يكون `published_at` فارغًا.

يتضمن `content/launch-news.json` نسخة من 80 خبرًا أُضيفت إلى مشروع NewsStand: عشرة أخبار لكل تصنيف. النصوص معاد صياغتها، وروابط المصادر وتواريخها محفوظة. الصور رسوم SVG أصلية توضيحية، وليست صورًا توثيقية للأحداث. لا يستورد التطبيق هذا الملف تلقائيًا؛ يقرأ الأخبار مباشرة من Supabase. لا تعاود إدخال البيانات فوق تعديلات المحررين.

عند غياب متغيري Supabase معًا تظهر بيانات العرض المحلية. إذا ضُبط أحدهما دون الآخر يظهر خطأ إعدادات بدل إخفاء المشكلة ببيانات تجريبية.

## النشر على Render

- النوع: Web Service، والبيئة Node.
- الفرع: `main`، والمجلد الجذري فارغ.
- Build Command: `npm ci && npm run build`
- Start Command: `npm run start -- -H 0.0.0.0`
- أضف `SUPABASE_URL` و`SUPABASE_PUBLISHABLE_KEY` في Environment.
- يستخدم الموقع `RENDER_EXTERNAL_URL` تلقائيًا لروابط SEO. عند ربط نطاق خاص، اضبط `SITE_URL` على أصله الكامل، مثل `https://example.com`.
- فعّل Auto-Deploy ليتبع النشر تحديثات الفرع.

ملفات `.env.local` و`node_modules` و`.next` مستبعدة من Git. لا تحتاج الواجهة إلى مفتاح service_role.

تتوفر `/sitemap.xml` و`/robots.txt` وبيانات NewsArticle ووسوم المشاركة. تبقى الفهرسة معطلة للعرض المحلي أو عند غياب عنوان عام. صفحة الخبر تتضمن رابط المصدر وتاريخ مادته، ولا تتضمن مربع ملخص تحت الصورة.
